# Digital Clock

## Description
A fullscreen digital clock application developed using Python and Tkinter. It displays the current system time in hours, minutes, and seconds.

## Features
- Fullscreen clock display
- Black background with white text
- Updates every second
- Simple graphical user interface

## Technologies Used
- Python
- Tkinter
- datetime
- time

## How to Run
1. Install Python 3.
2. Make sure Tkinter is installed.
3. Run the application:

```bash
python3 clock.py
```
